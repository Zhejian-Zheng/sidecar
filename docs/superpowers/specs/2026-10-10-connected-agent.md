# Sidecar：设备连接与手机控制入口

用户已要求继续实现项目。沿用现有 LangGraph 核心及 iPhone 入口、独立 Android 执行端路线；不宣称同机 iOS 后台操作。Microsoft To Do 尚未安装，模型尚未指定，因此本轮不执行真实账号任务或付费模型调用。

## 交付

1. 修复崩溃后取消占用；模型超时有限重试，每次重试前检查用户控制；补充聚焦输入。
2. AndroidDevice 使用 uiautomator2 经 ADB 观察和操作明确指定的设备。结构化控件与截图一起提供给模型；控件身份稳定，目标控件变化时拒绝旧操作，忽略不相关截图变化。纯坐标操作仍采用严格截图检查。限制允许操作的 App，敏感页面交接。中文输入通过 UiAutomator 输入接口。任何动作失败不自动重试。
3. 独立 worker + SQLite 待执行队列；网页提交与执行生命周期分离；进程重启后的中断任务等待人工恢复，绝不自动续做不确定动作。等待交接或暂停的任务保留环境，后续任务排队。任务、模型配置、执行设备固定在服务启动配置中。
4. FastAPI 提供手机适配页面与 API：提交、任务列表、状态、近期记录、最新观察截图、暂停、取消、带备注恢复。使用配对令牌保护 API，默认只监听 127.0.0.1。局域网须显式绑定，互联网部署要求 HTTPS。页面退出不影响 worker；页面内完成提示和返回时状态刷新已实现后才标记。iOS 关闭页面后系统推送需要 HTTPS、主屏幕 Web App 和授权，本阶段不冒充已完成。
5. 演示模式明确标记离线，界面输入待办列表；Android 模式自然语言目标由模型提取可验证条件，允许用户给出条件。只在选择 Android 模式且明确配置密钥、模型、设备和包名后发送观察。

## 边界与安全

- 初版一个执行环境、串行任务。设备同一 serial 的操作跨 home 互斥。两个人同时手动控制不在保证范围内；暂停确认后再接管。
- 页面内容不成为指令，目标 App 白名单与密码/登录/支付等检查只是保守防护，无法保证识别所有敏感内容。不允许自动操作任意包名或执行 shell。
- 没有模型配置仍能用离线任务验证后台执行和 UI；真实设备只做本地观察检查，不执行登录。
- 使用原生网页与本地资源，无第三方页面脚本。蓝白色工作台，任务输入在上，当前执行画面与逐步记录并列，窄屏纵向排布。颜色 #F3F7FC / #FFFFFF / #17324D / #1767D2 / #4B657D；系统中文字体；输入、状态、交接为视觉重点。
- 原有代码未提交，保留在当前工作区的新分支，不搬移或覆盖；不推送。按用户继续开发授权推进，不再次要求逐文档批准。
