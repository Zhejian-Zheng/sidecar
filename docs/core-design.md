# Sidecar 第一阶段：GUI Agent Harness

本阶段在用户授权开始开发后实现通用核心。设备环境、目标 App、最终模型仍未确定；不将离线演示视为真实手机任务完成。

## 范围

- Python + LangGraph 单 Agent 循环，设备与模型通过 Protocol 接入。
- Task 明确自然语言目标及验收条件；模型每轮输出一个有类型的动作。
- 支持 tap、type、swipe、back、wait、handoff、finish；控件信息与截图均来自设备观察。
- SQLite 检查点、事件记录、动作意图记录；本地工作目录同一时间只允许一个执行者。
- 人工交接通过 LangGraph interrupt；恢复时丢弃旧动作并重新观察。
- 每个有副作用动作执行前记录意图，结果未知则等待人工核对，不自动重复动作。
- 限制决策步数、连续无进展轮数、每次运行的时间；模型上下文仅带最近的摘要。
- 完成声明触发新观察及逐条条件验证；保留验证证据。
- 提供 CLI、持久化的离线演示环境和可配置的 LangChain ChatOpenAI 模型适配器。

## 边界

不在本阶段安装手机 App、接入真实设备、开发手机网页或实现付款。离线策略只验证 Harness，明确标注为规则演示，不宣称具备自然语言泛化能力。真实模型通过环境变量显式配置，不默认发送数据。

暂停与取消在步骤边界生效，不能撤回已开始的设备动作。运行时限是步骤边界检查，不是强制终止任意设备调用；具体设备适配器必须实现自己的超时。恢复不等于回滚 App，也不提供跨设备的 exactly-once 保证。

## 安全和数据

设备适配器是可信代码，必须标注敏感页面/控件并对动作给出 allow/handoff/deny 判定。通用核心不声称能识别所有支付、登录场景。凭据由用户在设备上输入，不交给模型。屏幕和记录可能包含私人信息，本地工作目录默认不提交 Git；只有显式启用模型后，当前观察和任务摘要才发给配置的提供商。

## 验收

自动化测试覆盖新观察、虚假完成、等待交接、跨实例恢复、取消、无进展限制、动作结果不确定、参数错误、设备不匹配和并发锁。CLI 离线演示能生成可读取的执行记录；配置真实模型的路径通过受控模型响应测试，不将其称作线上模型验收。
